# Amit 2.0 MotionKit

A lightweight, reusable generator for 15-20 second Instagram Reels. Built for minimal personal visibility and typography-led editorial motion.

## MVP
- 9:16 stage (1080x1920)
- Frame-based script editor: hook, tension, insights, takeaway, CTA
- Three presets: Contrarian Statement, 3-5 Tips, Mini Framework
- Preview, play/pause, restart
- Adjustable frame duration, type scale, accent colour and transition
- Export-ready rendering workflow; export MP4 using supported local/browser capture workflow
- Captions and post metadata export

## Visual defaults
Ink #191919, Paper #F3EFE5, Signal #E8753D, Stone #A8A69B, Sage #D6DCB9.

## How to run
Open `index.html` in a modern browser. No build step or dependencies.

## Important
Browser preview is not an MP4 export. Use a video-rendering/capture step and inspect the exported file before uploading. Respect music and image licensing.

## Folder map
- `index.html`: interface
- `styles.css`: visual system
- `app.js`: editor and animation
- `README.md`: usage notes
