# Template inventory

Build these masters once and reuse them:
- `reel-statement`: provocative statement + 3-4 message beats.
- `reel-tips`: numbered tips with a clear final takeaway.
- `reel-framework`: model / process / example.
- `carousel-7-slide`: hook, context, three insights, checklist, CTA.
- `framework-card`: concise framework visualisation.
- `design-clinic`: challenge, diagnosis, recommendations, next step.

Template rule: change the content, not the entire visual system.
